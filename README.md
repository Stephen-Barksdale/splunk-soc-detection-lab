# Splunk SOC Detection Lab

## Purpose

This repository demonstrates basic SIEM detection logic, Splunk SPL searches, log analysis, and incident documentation for cybersecurity operations roles.

## Skills Demonstrated

- Splunk SPL search concepts
- Windows Event Log review
- Linux authentication log review
- Failed login detection
- Brute-force pattern review
- Suspicious PowerShell investigation concepts
- Incident documentation
